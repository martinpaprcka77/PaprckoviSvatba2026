💡 Doporučení

001 je nejlepší vstup pro další iteraci.
22KB, čistý checklist, žádný budget noise. Když přidat budget tracking, filtr podle osob a GitHub sync, vznikne ideální v3 — jednoduchá jako 001, výkonná jako v2.
Držet 100k hard cap.
LastSvatba (146k) a v2_ultimate (116k) ukazují, že bez limitu budget roste. Excel s podmíněným formátováním a SUMIF vzorci tento problém řeší.
Neztratit Děti.
Ve verzi 17.5. Děti zmizely z úkolů. Opraveno 21.5. — pravidlo "nikdy neodebírat" je teď v CLAUDE.md i wedding-data-integrity.
Návrat k jednoduchosti.
54KB verze s GitHub API a PIN lockem jsou moc složité na údržbu. Pro další vývoj: vzít strukturu 001, přidat budget bar z LastSvatba, osobní filtr z PuvodnuApp. Nic víc.
